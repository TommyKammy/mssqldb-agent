# Constitution

## Purpose

This repository is operated with AI-assisted planning and execution. Durable project knowledge must live in repository files, not in a single AI thread.

## Non-negotiables

- Do not execute production-changing SQL automatically in milestone 1.
- Prefer deterministic diagnostics before LLM inference.
- Make risk and confidence explicit in recommendations.
- Keep implementation slices small enough to fit one issue and one PR.
- Do not declare work complete while focused verification still fails.

## AI workflow rules

- Read repo memory files before broad changes.
- Treat GSD planning docs as upstream intent.
- Treat GitHub issue metadata as authoritative for execution order.
- If requirements are ambiguous, update repo memory or issue text instead of improvising hidden policy.
